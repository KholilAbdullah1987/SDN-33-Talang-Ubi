Panduan Hosting Rumah MPI SDN 33 Talang Ubi

Struktur Folder Wajib Saat Di-Hosting:

Letakkan 3 file berikut dalam satu folder utama yang sama agar logo dan banner animasi tampil otomatis:

  • 📁 folder-web-sdn33/
  • ├── 📄 index.html (File aplikasi web ini)
  • ├── 🖼️ logo-resmi-sdn33.jpg (Logo Resmi SDN 33 Talang Ubi)
  • └── 🎞️ Animated MPI School Welcome Banner_2.gif (Banner Utama)
Rekomendasi Layanan Hosting Gratis & Mudah:
  1. Netlify Drop (Paling Cepat): Buka app.netlify.com/drop, lalu seret (drag & drop) folder berisi index.html, logo-resmi-sdn33.jpg, dan Animated MPI School Welcome Banner_2.gif. Website langsung online dalam 10 detik!
  2. GitHub Pages: Buat repositori baru di GitHub, unggah ketiga file tersebut, lalu aktifkan Settings → Pages → Branch main.
  3. Google Sites Sekolah: Sematkan (Embed) tautan hasil hosting Netlify/GitHub Pages ke dalam Google Sites SDN 33 Talang Ubi.
